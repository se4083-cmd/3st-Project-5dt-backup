## 주차 내 작업 순서와 산출물

1. 환경·디자인 기반: package, Vite 설정, CSS 공통 토큰, AppShell.
2. UI 상태: AsyncState와 프로필/응답 상태 선택기.
3. 운영 홈: Workload·문의 미리보기·후속 업무·분석 시점 분리.
4. 연결 경계: Session/Overview DTO, 응답 검증, 권한·범위 수명 관리.
5. 인수: 단위/컴포넌트 테스트, 빌드, 브라우저 확인, 계약 문서.

## 검증 기록

- 자동 검사 22개 통과. 활성 ADMIN 조건, 다른 사용자/범위 응답 거부, 음수·중복·형식 오류 거부, 분모 0 처리, 기한과 같은 시각은 초과 아님.
- 네트워크 오류 처리, 임의 API 경로 호출 방지, 서버 원문 오류 비노출, 읽기 요청만 실행.
- 이전 요청의 늦은 결과 무시와 unmount 시 취소, 401~503에서 이전 업무 데이터 제거.
- 정상/빈/미집계/이전 정상 결과 표시, 필터 이동, 직접 URL 권한 제한, 시연 로그아웃 복구.
- TypeScript 검사와 프로덕션 번들 생성 성공.
- 브라우저의 좁은 패널에서 홈 배치, 문의 경로 연결, 배송팀 전환 후 다른 팀 문의 제거 확인.
- 데스크톱 1440/1024px 전 해상도·스크린리더·실서버 통합·실제 계정 변경은 별도 검증 필요.
