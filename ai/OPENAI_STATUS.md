# OpenAI 담당 작업 상태

기록일: 2026-11-03 (한국 시간)

## 현재 상태를 읽는 방법

현재 반품 안내 초안은 **연결 대기이며 실제 생성 기능은 미구현**입니다.
진입점 파일이 있다는 이유로 생성·검증·RAG 통합이 완료됐다고 해석하면 안 됩니다.
이 문서는 GPT나 다음 작업자가 완료한 일과 미완료 기능을 구분하기 위한 인계 기록입니다.

## 완료 내용

- 기존 문의 분류·신호 추출 코드를 보존했습니다. 기존 CLI와 함수를 변경하지 않았습니다.
- 반품 안내 진입점 `generate_return_draft`를 추가했습니다. 호출하면
  `NotImplementedError`로 대기를 명시하며 API 호출이나 입력 데이터 처리를 하지 않습니다.
- 이번 작업에서 먼저 만들었던 합성 문의·정책·응답 및 자체 정책/RAG 입력 구조와
  생성 구현은 사용자 요청에 따라 제거했습니다. 기존 추적 자료는 삭제하지 않았습니다.
- 다른 팀의 정책 검색·유효성 판단·주문 권한·이관·승인·저장·발송 영역은 구현하지 않았습니다.
- 필요한 팀 입력과 이후 연결 항목을 문서화하고 미확정 입력란을 비워 두었습니다.

## 변경 파일

| 파일 | 변경 목적 |
| --- | --- |
| `ai/draft_return.py` | API를 호출하지 않는 구현 대기 진입점 |
| `ai/test_draft_return.py` | 대기 상태와 API 미호출 확인 |
| `ai/RETURN_DRAFT_README_KO.md` | 담당 범위, 필요한 입력, 빈 연결 항목, 실행 설명 |
| `ai/OPENAI_STATUS.md` | 완료·미완료·검증·후속 작업 인계 기록 |

위 4개 파일 외 기존 소스·공통 설정·팀 데이터는 이번 변경에 포함하지 않습니다.
환경 파일, 인증 정보, 가상환경, 실행 로그는 커밋 대상에 포함하지 않습니다.

## 테스트 결과

2026-11-03 현재 코드에서 다음 검증을 직접 실행했습니다.

- 단위 테스트 **2개 통과**: 미설정 호출이 명시적으로 중단됨 / 전달된 client가 호출되지 않음.
- `git diff --cached --check` 통과.
- 이번 테스트에서 실제 Azure/OpenAI API 호출 **0회**.
- 합성 문의·정책·응답이나 다른 팀 데이터를 이번 테스트에 사용하지 않았습니다.

앞서 보고한 22개 합성 테스트는 제거 전 코드의 결과이며 현재 기능의 검증 결과가 아닙니다.
인계문의 2026-11-02 분류 12/12·신호 16/16도 과거 기록이며 이번에 재실행하지 않았습니다.
실제 모델 응답 품질, 인증·배포 접근, 정책 기반 생성, 백엔드 통합은 미검증입니다.

현재 로컬 가상환경은 Python 3.14 / OpenAI SDK 3.42.1입니다.
저장소 루트에서 가상환경을 활성화한 후 다음 명령으로 검증할 수 있습니다.

```powershell
python -m unittest discover -s ai -p test_draft_return.py -v
```

## 남은 문제와 필요한 입력

대기 상태를 유지하기 위해 지금 추가로 채울 값은 없습니다. 실제 초안 생성을 시작하려면
담당자가 GitHub에 게시한 다음 자료가 필요합니다. 임의 계약이나 합성 자료로 대체하지 않습니다.

| 시작 전 필요한 항목 | 확정된 GitHub 경로/링크 |
| --- | --- |
| OpenAI가 받을 정책/RAG 입력 계약과 책임 경계 | |
| 사용이 승인된 일반 반품 신청 정책 근거 | |

그 외 문서 식별자·버전·조항·해시, 오류 전달, 초안 출력, 주문 정보 연결 방식은
`RETURN_DRAFT_README_KO.md`의 빈 항목으로 남겼습니다. 함수의 현재 인자도 임시 자리이며
공통 계약이 아닙니다. 이번 코드를 실행 가능한 서비스 기능으로 연결하지 않습니다.

1. 담당자가 관련 문서·코드를 GitHub에 게시하면 해당 변경과 책임 경계를 읽습니다.

4. 담당자가 제공한 사용 가능한 자료로 검증합니다. 필요한 자료가 없으면 대기를 유지합니다.

다른 팀의 기능이나 공통 인터페이스를 먼저 구현하지 않습니다. 고객 발송·주문/금전/계정 변경은
현재 작업 범위에 포함하지 않습니다.
